# World War Bot

Discord上で遊べるリアルタイム領土争奪・世界征服シミュレーションBotです。

---

## 📖 概要

**World War Bot** は、Discord サーバー上で複数のプレイヤーが領土（実在の国）を奪い合い、自国の経済・軍事力を強化しながら世界征服を目指す本格シミュレーションゲームBotです。

自動生成される世界地図、防衛・投資・宣戦布告・奇襲システム、国連（UN）や陣営（Camp）による外交・同盟システムなど、多彩な機能を備えています。

---

## ✨ 主な機能

- **🚩 建国ウィザード & 超かんたん操作**: `/start` で国（日本やアメリカなど）を選ぶだけで即建国！`/command` でボタン操作のみでプレイ可能。
- **🤖 ソロでも遊べるNPC/反乱軍システム**: 定期的に反乱軍(CPU)が空き地を侵攻。討伐するとボーナス資金（+500 Gold）を獲得！
- **🗺️ リアルタイム世界地図生成**: 領土の占領状況に応じて世界地図画像（`base_map.png` / `mask_map.png`）を自動生成・出力。
- **💰 経済・軍事システム**: 定時給付、労働（`/work`）、石油資源管理、防衛投資（`/defend`）、防衛力再分配（`/reallocate`）、戦債発行（`/war_bonds`）。
- **⚔️ 遠征・戦闘システム**: 隣接国攻撃、遠征ペナルティ計算、正規の宣戦布告と奇襲攻撃。
- **🤝 外交・陣営システム**: 国連（UN）への加盟、プレイヤー同士の陣営（Camp）結成、同盟・密談チャット（`/say`）。
- **🌐 マルチワールド対応**: 複数の世界（ワールド）の切り替え・管理に対応。

---

## 🎮 主なコマンド

| コマンド | 説明 |
| :--- | :--- |
| `/start` | 【初心者向け】好きな国（首都）を選んで建国ボーナスを獲得します。 |
| `/command` | ボタン操作で労働・防衛・出撃がすべて完結する国家司令部を開きます。 |
| `/help` | ゲームのルール、初期設定、詳細なヘルプを表示します。 |
| `/status` | 自分の所有領土・資金・石油・所属陣営などのステータスを確認します。 |
| `/work` | 労働を行って資金（国連加盟時は石油ボーナスも）を獲得します。 |
| `/attack` | 指定した国・領土へ攻撃を行います（`/command` のボタンからも実行可能）。 |
| `/defend` | 領土の防衛力を強化します。 |
| `/map` | 現在の世界情勢マップ画像を生成して表示します。 |
| `/op_setup` | 【管理者用】ゲーム用カテゴリと専用チャンネルを一括作成します。 |
| `/op_npc` | 【管理者用】反乱軍(NPC)システムのON/OFFを切り替えます。 |
| `/donate` | 開発者への支援情報を表示します。 |
