# World War Bot

Discord上で動作する領土争奪シミュレーションBot。

---

## 概要

**World War Bot** は、Discordサーバー上で実在の国・領土を奪い合い、自国の経済や軍事力を強化しながら世界征服を目指すシミュレーションゲームBotです。

自動生成される世界地図、防衛・投資・宣戦布告システム、国連（UN）や陣営（Camp）による外交・同盟機能などを備えています。

---

## 主な機能

- **建国**: `/start` で国（日本やアメリカなど）を選択して建国。`/command` によるボタン操作にも対応。
- **NPC/反乱軍**: 定期的に反乱軍(CPU)が空き地へ侵攻。討伐によるボーナス資金の獲得。
- **世界地図生成**: 領土の占領状況に応じて世界地図画像（`base_map.png` / `mask_map.png`）を生成・送信。
- **経済・軍事**: 定時給付、労働（`/work`）、石油資源管理、防衛投資（`/defend`）、防衛力再分配（`/reallocate`）、戦債発行（`/war_bonds`）。
- **戦闘**: 隣接国攻撃、遠征ペナルティ計算、宣戦布告および奇襲攻撃。
- **外交・陣営**: 国連（UN）への加盟、プレイヤー同士の陣営（Camp）結成、同盟・密談チャット（`/say`）。
- **マルチワールド**: 複数の世界（ワールド）の切り替え・管理に対応。

---

## 主なコマンド

| コマンド | 説明 |
| :--- | :--- |
| `/start` | 国（首都）を選んで建国します。 |
| `/command` | ボタン操作で労働・防衛・出撃を実行できる司令部パネルを表示します。 |
| `/help` | ゲームのルール、初期設定、詳細なヘルプを表示します。 |
| `/status` | 所有領土・資金・石油・所属陣営などのステータスを確認します。 |
| `/work` | 労働を行って資金（国連加盟時は石油ボーナスを含む）を獲得します。 |
| `/attack` | 指定した国・領土へ攻撃を行います。 |
| `/defend` | 領土の防衛力を強化します。 |
| `/map` | 現在の世界情勢マップ画像を生成して表示します。 |
| `/op_setup` | 管理者用: ゲーム用カテゴリと専用チャンネルを作成します。 |
| `/op_npc` | 管理者用: 反乱軍(NPC)の有効・無効を切り替えます。 |
| `/donate` | 開発者への支援情報を表示します。 |
